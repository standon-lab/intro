## 01. 노션의 기본 구성 요소 7가지

| 구성 요소 | 역할 | 비유 |
| --- | --- | --- |
| 계정 | 로그인 및 사용자 식별 | 신분증 |
| 워크스페이스 | 독립적인 업무 공간 | 회사 |
| 팀스페이스 | 업무 영역 및 협업 공간 | 부서 |
| 페이지 | 문서 작성 및 하위 문서 관리 | 폴더 + 문서 |
| 블록 | 텍스트, 이미지, 표 등 | 문서 구성 요소 |
| 데이터베이스 | 자료 분류 및 검색 | 엑셀 관리대장 |
| 대시보드 | 전체 자료 및 업무 현황 관리 | 종합 상황판 |

## 02. 전체 계층 구조

- 계정
  - 워크스페이스
    - 팀스페이스 A — 고객 프로젝트
      - 프로젝트 001
        - 고객 요구사항
        - 광고 기획안
        - 미팅 보고서
      - 프로젝트 002
    - 팀스페이스 B — 광고 제작
      - 이미지 제작
      - 동영상 제작
    - 개인 페이지
      - HOME 대시보드
        - DOCUMENT MASTER
      - 개인 자료
      - 아이디어 노트
      - 백업 자료

팀스페이스와 개인 페이지는 목적과 접근 권한을 기준으로 구분한다.

## 04. 팀스페이스와 개인 페이지

| 구분 | 팀스페이스 | 개인 페이지 |
| --- | --- | --- |
| 목적 | 업무 및 협업 | 개인 및 비공개 |
| 사업계획 | 적합 | 비공개 초안 |
| 고객 프로젝트·광고 제작 | 적합 | 필요 시 비공개 초안 |
| 공동 업무 매뉴얼 | 적합 |  |
| 개인 메모·아이디어·학습 |  | 적합 |
| 개인 백업·개인용 HOME |  | 적합 |

팀스페이스는 지속적인 업무 영역별로 만들고, 프로젝트는 그 안의 상위 페이지로 만든다. 프로젝트마다 팀스페이스를 만들 필요는 없다. 고객 공유 시 상위 페이지에서 상속되는 권한을 확인한다.

## 05. 페이지는 폴더이자 문서

하위 페이지를 생성하여 자료를 분류할 수 있고, 상위 페이지 자체에도 텍스트, 이미지, 영상, 표, 프로젝트 개요와 현황을 작성할 수 있다.

| 아이콘 | 용도 |
| --- | --- |
| 🏠 | HOME 대시보드 |
| 📁 | 분류 및 폴더 역할 |
| 📄 | 일반 문서 |
| 📘 | 매뉴얼 및 가이드 |
| 📊 | 데이터베이스 |
| 💡 | 아이디어 |
| 📚 | 학습 자료 |
| 🎨 | 광고 및 디자인 |
| 🗃️ | 보관 및 백업 |

아이콘은 시각적 구분이며 기능은 동일하다.

## 06. 대시보드와 DOCUMENT MASTER

팀스페이스 및 개인 페이지 → DOCUMENT MASTER → HOME 대시보드

| 구성 | 역할 |
| --- | --- |
| 원본 페이지 | 실제 문서 작성 및 수정 |
| DOCUMENT MASTER | 원본 링크, 분류, 상태, 태그 및 검색 |
| HOME | 문서 탐색 및 빠른 접근 |

원본은 한곳에 두고 링크로 관리한다. 등록된 데이터베이스의 보기는 속성 변경 시 자동 반영되지만, 외부에서 새로 만든 페이지는 자동 수집되지 않는다. 목록 수정일은 원본 수정일과 다르다.

## 07. 구축된 대시보드

- BIGPYCRAFT HOME — 개인 지식 및 프로젝트 관리, 최초 28개 등록.
- STANDON HOME — 광고 에이전시 업무 관리, 최초 28개 등록. 해당 계정의 접근 권한 필요.
- BLUENINE HOME — 계정 연결 완료, 대시보드 미구축.
- DOCUMENT MASTER · 통합 문서 관리

기존 원본 문서는 이동하거나 삭제하지 않았다. 새 페이지 자동 수집 기능은 아직 구축하지 않았다.

## 08. 새로운 문서 작성 방법

1. 계정 선택: 개인 학습은 빅파이, 광고 업무는 스탠드온.
2. 저장 위치 결정: 업무는 팀스페이스, 비공개 자료는 개인 페이지.
3. 관련 프로젝트 또는 주제의 상위 페이지 선택.
4. 하위 페이지에 실제 기획안, 보고서, 회의록 작성.
5. DOCUMENT MASTER에 원본 링크, 분류, 상태 등록.
6. HOME에서 통합 목록과 관련 보기를 확인.

### ChatGPT 요청 예시

**업무 문서 작성**

스탠드온 노션의 관련 팀스페이스에 문서를 작성하고 DOCUMENT MASTER에도 등록해줘. 기존 원본 문서는 변경하지 마.

**개인 문서 작성**

빅파이 노션의 개인 페이지에 학습 내용을 정리하고 DOCUMENT MASTER에도 등록해줘.

**문서 관리**

빅파이 노션의 기존 문서와 DOCUMENT MASTER를 비교해서 누락된 문서만 중복 없이 등록해줘. 원본 문서는 변경하지 마.

## 09. 문서 제목 작성 규칙

추천 형식: \[문서 분류\] 문서 제목 — YYYY-MM-DD

| 분류 | 제목 예시 |
| --- | --- |
| 기획 | \[기획\] 광고 캠페인 기획안 |
| 회의 | \[회의\] 고객사 미팅 — 2026-11-24 |
| 학습 | \[학습\] 오파독 4주차 강의 |
| 가이드 | \[가이드\] GitHub 사용법 |
| 기술 | \[기술\] MCP 연결 방법 |
| 보고 | \[보고\] 광고 제작 결과 보고서 |
| 백업 | \[백업\] 기존 업무 자료 |

날짜는 필요한 문서에 붙이고 지속 업데이트하는 매뉴얼은 생략 가능하다.

## 10. 무료 요금제 관리 원칙

| 항목 | 관리 방법 |
| --- | --- |
| 팀스페이스 | 필요한 업무 영역별 생성 |
| 워크스페이스 멤버 | 1인 운영 시 불필요한 멤버 추가 방지 |
| 고객 공유 | 필요한 페이지에 게스트 초대 |
| 파일 업로드 | 무료 요금제 파일당 5MB 제한 고려 |
| 대용량 이미지·영상 | Google Drive 등에 보관 후 링크 |
| 대시보드 | 무료 기능 중심 구성 |
| 블록 사용량 | 실제 계정의 사용량 및 요금제 설정 확인 |

팀스페이스 생성과 유료 전환은 별개다. 멤버 수, 블록 사용량 및 고급 기능 제한에 유의한다. 요금제 조건은 변경될 수 있으므로 실제 계정 설정과 공식 안내를 확인한다.

## 11. 노션 관리 체크리스트

- [ ] HOME 대시보드를 즐겨찾기에 등록하기
- [ ] 업무 문서와 개인 문서를 구분하기
- [ ] 팀스페이스를 지나치게 많이 만들지 않기
- [ ] 관련 문서는 상위 페이지 아래에 작성하기
- [ ] 페이지 계층은 가능하면 2\~3단계로 관리하기
- [ ] 문서 제목과 아이콘을 일관되게 사용하기
- [ ] 원본 문서를 불필요하게 복제하지 않기
- [ ] 새 문서는 DOCUMENT MASTER에 등록하기
- [ ] 오래된 문서는 삭제 전에 보관 여부 검토하기
- [ ] 고객 공유 전 페이지 접근 권한 확인하기

## 12. 이것만은 꼭 기억하세요

- 워크스페이스: 사용 목적별 공간 구분.
- 팀스페이스: 업무 영역별 구분.
- 상위 페이지: 프로젝트와 주제별 구분.
- 하위 페이지: 실제 문서 작성.
- 개인 페이지: 개인 자료와 비공개 문서 관리.
- DOCUMENT MASTER: 모든 등록 문서의 위치와 정보 관리.
- HOME: 필요한 문서를 한곳에서 탐색.

> 🎯 노션 관리의 목적은 문서를 많이 만드는 것이 아니라, 필요한 문서를 필요할 때 쉽게 찾는 것이다. 당분간 HOME을 중심으로 실제 문서를 작성하며 익숙해지자.
